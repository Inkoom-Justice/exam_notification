📧 EmailJS Config

Setup steps:
1. Create account at emailjs.com
2. Add an Email Service (Gmail recommended)
3. Create an Email Template using the variables shown below
4. Paste your IDs here
Template variables to use:
{{to_name}} — invigilator's first name
{{to_email}} — recipient email
{{exam_subject}} — e.g. "Mathematics"
{{exam_component}} — paper name
{{exam_date}} — formatted date
{{exam_time}} — start time
{{exam_room}} — room number
{{role}} — "Main Invigilator" or "Backup"
{{readiness_time}} — 20 min before start
